Movie API Documentation

Welcome to the Movie API documentation. This API allows developers to access and retrieve information about movies.

Movies

Request URL Response
GET /movies Retrieve a list of all movies
GET /movies/:title Retrieve information about a specific movie
POST /movies Create a new movie
PUT /movies/:title Update information for a specific movie
DELETE /movies/:title Delete a specific movie

Users

Request URL Response
POST /users Create a new user
GET /users Retrieve a list of all users
GET /users/:users Retrieve information about a specific user
PUT /users/:users Update information for a specific user
DELETE /users/:users Delete a specific user
